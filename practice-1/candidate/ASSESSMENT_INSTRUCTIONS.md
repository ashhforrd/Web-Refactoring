# Production Engineering Assessment

You have **90 minutes**.

This repository is a working application that contains multiple production
engineering problems. Problems may concern security, performance, reliability,
observability, testing, or developer tooling.

Your task is to audit the existing behavior, diagnose root causes rather than
only visible symptoms, and make minimal, targeted fixes. Backwards compatibility
matters, and the existing tests should continue to pass.

Commit fixes atomically. Create an `ASSESSMENT.md` describing the findings you
investigated, their impact, your reasoning, the changes you made, and how you
verified them. You do not necessarily need to fix every issue; unresolved but
well-diagnosed findings may still be documented.
