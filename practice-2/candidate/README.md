# RelayDesk

RelayDesk is a local support operations workspace. Teams receive customer tickets, collaborate with internal notes, assign owners, close requests, and process an outbox of customer notifications.

## Run locally

```sh
pnpm install
pnpm db:seed
pnpm dev
```

The web app runs at http://localhost:5173 and the API at http://localhost:4100. Demo login: `maya@example.test` / `demo-password`.
